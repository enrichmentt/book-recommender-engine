# Book Recommender Engine

Прототип рекомендательного сервиса для книг на датасете Goodbooks-10k.
Собрал и сравнил четыре подхода: топ популярного, контентную модель на
TF-IDF, item-based коллаборативную фильтрацию и SVD. Метрики —
Precision@K, Recall@K, nDCG@K и RMSE.

Весь процесс (разбор данных, код, графики, выводы) — в ноутбуке
`book_recommender.ipynb`.

## Данные

Датасет **Goodbooks-10k** с Kaggle:
https://www.kaggle.com/datasets/zygmunt/goodbooks-10k

Скачанные файлы нужно положить в папку `data/`.

| Файл | Что внутри | Строк |
|---|---|---:|
| `ratings.csv` | оценки `user_id, book_id, rating` (1–5) | 981 756 |
| `books.csv` | метаданные книг: название, автор, год и т.д. | 10 000 |
| `tags.csv` | справочник тегов | 34 252 |
| `book_tags.csv` | какие теги присвоены каким книгам | 999 912 |

По ходу EDA всплыло то, что обычно и бывает с такими данными:

| Характеристика | Значение |
|---|---:|
| Пользователей | 53 424 |
| Средняя оценка / доля оценок ≥ 4 | 3.86 / 66.2% |
| Медиана оценок на пользователя | 8 |
| Заполненность матрицы «пользователь × книга» | ~0.18% |

То есть оценки смещены в сторону высоких (всем всё нравится), матрица
почти пустая, а у пользователей и книг классический длинный хвост —
разреженность, перекос в популярное и холодный старт во всей красе.

## Что получилось

Тест — отложенная выборка, сплит 80/20 внутри каждого пользователя.
Релевантной считал книгу с оценкой ≥ 4, метрики на K = 10, усреднение
по 2000 пользователей из теста:

| Модель | Precision@10 | Recall@10 | nDCG@10 | RMSE |
|---|---:|---:|---:|---:|
| Popularity | 0.0014 | 0.0061 | 0.0034 | — |
| Item-Based CF | **0.0077** | **0.0410** | **0.0214** | — |
| SVD | 0.0002 | 0.0009 | 0.0011 | **0.836** |

Самое интересное: SVD даёт лучший RMSE, но в топ-N её рекомендации
хуже даже популярного — она училась предсказывать оценку, а не
ранжировать, и на разреженных данных её топ вырождается почти в ту же
популярность. Item-based CF здесь работает заметно лучше: соседству
похожих книг хватает пары оценок, чтобы выдать что-то осмысленное.

Контентную модель метриками не гонял — она про другое: находить похожие
книги (`get_similar_books`) и закрывать холодный старт новых книг, у
которых ещё нет оценок.

Из этого и следует итоговая схема — гибрид: новым книгам — контентная
модель, новым пользователям — популярное, а как только набираются
оценки — подключать CF/SVD.

## Как запустить

```bash
python -m venv .venv

# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
jupyter notebook book_recommender.ipynb
```
